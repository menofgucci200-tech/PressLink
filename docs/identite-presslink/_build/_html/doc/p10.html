02 · Le logo

Les versions

Quatre assemblages, toujours à partir des mêmes éléments. Leurs proportions sont fixées : on ne recompose pas le logo soi-même.

Horizontal · version principale

C'est le logo par défaut : site, documents, signature, publicités. À utiliser dès que la place le permet.

Empilé

Pour les formats carrés ou verticaux : affiches, autocollants, écrans de démarrage, couvertures.

Symbole seul

Quand la marque est déjà nommée ou que la place manque : icône d'application, favicon, avatar, broderie, tampon.

Nom seul

Usage rare : quand le symbole est déjà présent à proximité (par exemple sur une page où l'icône est affichée).
