Les règles

  • Le texte courant est en nuit (ou gris texte) sur fond blanc ou fond clair.
  • Le bleu clair ne s'utilise que sur fond sombre.
  • Le vert est réservé à une seule action par écran ou par page. Texte blanc en gras d’au moins 14 pt sur le vert action ; pour un petit bouton, utiliser le vert foncé #15803D.
  • On n'utilise jamais la couleur seule pour transmettre une information : on ajoute toujours un mot ou une icône.
