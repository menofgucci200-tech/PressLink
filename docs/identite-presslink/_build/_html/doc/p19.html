Pourquoi ces deux familles

Bricolage Grotesque a du caractère : des formes un peu irrégulières, chaleureuses, qui évitent l'effet « logiciel froid ». Plus Jakarta Sans est très lisible sur petit écran, avec des chiffres nets pour les montants.

Les deux sont sous licence SIL Open Font : gratuites, utilisables sur le web, en impression et en application, et disponibles sur Google Fonts.

Police de secours

Si ces polices ne sont pas disponibles (Word, PowerPoint sans installation), utiliser Arial : gras pour les titres, normal pour le texte. Le logo, lui, reste toujours une image.

Le nom « PressLink » du logo est un dessin, pas une police : aucune des deux familles ne le reproduit.
