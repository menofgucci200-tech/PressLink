Règles de composition

  • Aligné à gauche, jamais justifié. Centré seulement pour les titres courts d'affiche.
  • Interlignage : 1,5 pour le texte, 1,05 à 1,15 pour les titres.
  • Lignes de 45 à 75 caractères pour un texte confortable.
  • Un mot en couleur au maximum par titre (en bleu, ou surligné en or).
  • Pas de capitales pour les phrases ; réservées aux petits surtitres espacés.
