Bon à savoir

  • SVG : format vectoriel, net à toutes les tailles. À préférer partout où il est accepté.
  • PNG : image avec fond transparent, pour Word, PowerPoint, WhatsApp, réseaux sociaux.
  • PDF : pour l'imprimeur. Demander une épreuve avant le tirage complet.
  • Pour un format qui manque (EPS, AI, broderie DST), demander à l'équipe : il est produit depuis les fichiers maîtres.
